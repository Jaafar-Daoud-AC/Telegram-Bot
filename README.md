## 📖 نبذة عن المشروع

هذا المشروع هو **أول بوت تلغرام قمت بتطويره**، وقد بنيته أثناء رحلة تعلّمي لكيفية صناعة بوتات تلغرام باستخدام لغة **Python** ومكتبة **pyTelegramBotAPI**.

البوت يقدّم خدمات يومية بسيطة وعملية داخل المحادثة مباشرة:

- أسعار الذهب في مصر بحسب العيار.
- أسعار صرف الدولار الأمريكي مقابل عدة عملات.
- حاسبة سريعة.
- محوّل من نسبة إلى ديسيبل (dB).

> 💡 **ملاحظة:** المشروع تعليمي بالدرجة الأولى، والهدف منه تطبيق المفاهيم الأساسية لبناء البوتات بشكل عملي ومنظّم.

## ✨ المميزات

| الأمر | الوصف | مثال |
|-------|-------|------|
| `/start` أو `/help` | رسالة الترحيب وقائمة الأوامر | `/help` |
| `/gold` | أسعار الذهب في مصر (عيار 24 و21 و18 و14 و10) بيعًا وشراءً | `/gold` |
| `/dollar` | سعر 1 دولار مقابل الليرة السورية والجنيه المصري والليرة التركية واليورو | `/dollar` |
| `/calc` | حاسبة للعمليات الحسابية الأساسية | `/calc 5*(2+3)` |
| `/db` | تحويل النسبة إلى ديسيبل للقدرة وللجهد | `/db 100` |

### مميزات إضافية

- 💬 **الرد على الكلمات العادية:** يمكنك كتابة «ذهب» أو «دولار» أو «gold» أو «dollar» بدون الأمر.
- ⚡ **تخزين مؤقت (Cache):** تُحفظ النتائج لمدة 10 دقائق حتى لا يُرسل البوت طلبًا إلى المصدر مع كل رسالة.
- 🛡️ **معالجة الأخطاء:** رسائل واضحة عند فشل جلب البيانات أو عند إدخال قيمة غير صحيحة.
- 🔒 **أمان الحاسبة:** تقبل رموزًا محددة فقط (أرقام و `+ - * / % ( )`) وتمنع الأسس والعمليات الطويلة.
- 🔑 **حماية التوكن:** يُحفظ التوكن في ملف `.env` ولا يُرفع إلى GitHub.
- 📋 **قائمة أوامر تلقائية:** تظهر الأوامر في قائمة تلغرام عبر `set_my_commands`.

## 🚀 طريقة التشغيل

### 1) المتطلبات

- Python 3.8 أو أحدث
- حساب تلغرام وتوكن بوت من [@BotFather](https://t.me/BotFather)

### 2) تحميل المشروع

```bash
git clone https://github.com/YOUR_USERNAME/pot_telegram.git
cd pot_telegram
```

### 3) تثبيت المكتبات

```bash
pip install -r requirements.txt
```

### 4) إعداد التوكن

انسخ ملف المثال وأنشئ ملف `.env`:

```bash
cp .env.example .env
```

ثم افتحه وضع التوكن الخاص بك:

```env
BOT_TOKEN=your_token_here
```

### 5) تشغيل البوت

```bash
python bot_telegram.py
```

افتح البوت في تلغرام وأرسل `/start` 🎉

## 🎓 ماذا تعلّمت من هذا المشروع؟

بما أنه أول بوت لي، فقد كان هذا المشروع فرصة لتعلّم عدة مفاهيم أساسية:

- إنشاء بوت جديد عبر **BotFather** والحصول على التوكن.
- التعامل مع الأوامر والرسائل باستخدام **Message Handlers** (`message_handler`).
- تشغيل البوت باستمرار عبر **Polling** (`infinity_polling`).
- تعريف قائمة الأوامر داخل تلغرام باستخدام `set_my_commands`.
- استخراج البيانات من المواقع بتقنية **Web Scraping** و**Regular Expressions**.
- التعامل مع **REST API** وقراءة استجابات JSON.
- تطبيق فكرة **التخزين المؤقت (Caching)** لتقليل الطلبات وتسريع الرد.
- **التحقق من المدخلات** و**معالجة الاستثناءات** (`try / except`).
- حماية المعلومات الحساسة بالمتغيرات البيئية (`.env`) وملف `.gitignore`.
- تقسيم المشروع إلى **وحدات (Modules)** مستقلة.
